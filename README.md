## Как запустить

Требования: Node.js 18+ и npm (Vite 5).

```bash
git clone --branch master https://github.com/Liker4ik26/weblaba.git
cd weblaba
npm ci
npm run dev
```

Для сборки: `npm run build`. Node.js должен поддерживать Vite 5 (Node 18+).
